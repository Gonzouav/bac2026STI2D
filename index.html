M1Limites d'une fonction & Asymptotes
★▾
Définitions
  • Asymptote horizontale : si limx→±∞ f(x) = L → équation y = L
  • Asymptote verticale : si limx→a f(x) = ±∞ → équation x = a
  • Asymptote oblique : si limx→±∞ [f(x) − (ax+b)] = 0 → équation y = ax+b
Lecture graphique
// Sur le graphe, repérer : Horizontale → la courbe se rapproche d'une droite horizontale en ±∞ Verticale → la courbe "s'emballe" près d'un x = a Oblique → la courbe se rapproche d'une droite y=ax+b en ±∞
Limites usuelles à connaître
ex → +∞
limx→+∞ eˣ = +∞
ex → 0
limx→−∞ eˣ = 0
ln(x) → +∞
limx→+∞ ln x = +∞
ln(x) → −∞
limx→0⁺ ln x = −∞
Priorité
L'exponentielle l'emporte sur tout polynôme : lim eˣ/xⁿ = +∞ en +∞. Le logarithme croît moins vite que x : lim ln(x)/x = 0 en +∞.
M2Fonction Exponentielle
★★★▾
Propriétés fondamentales
  • Domaine : ℝ → Image : ]0 ; +∞[ (jamais nulle, jamais négative)
  • (eˣ)' = eˣ : elle est sa propre dérivée !
  • Strictement croissante sur ℝ ; convexe
  • e⁰ = 1 ; e¹ = e ≈ 2,718
Formules algébriques — SAVOIR PAR CŒUR
e^(a+b) = eᵃ × eᵇ // produit → somme des exposants e^(a-b) = eᵃ / eᵇ // quotient → différence (eᵃ)ⁿ = e^(na) // puissance → produit e^(-x) = 1/eˣ // inverse e^0 = 1
Fonctions du type eu
// Dérivée (règle de la chaîne) : (eᵘ)' = u' × eᵘ // Primitive : ∫ u' × eᵘ dx = eᵘ + C // Exemple : f(x) = e^(3x²+1) → f'(x) = 6x × e^(3x²+1)
Résolution d'équations / inéquations
e^f(x) = e^g(x) ⟺ f(x) = g(x) e^f(x) = k (k>0) ⟺ f(x) = ln(k) e^f(x) > 0 → TOUJOURS vrai (pas de condition) e^f(x) > k (k>0) ⟺ f(x) > ln(k)
⚠️ Pièges fréquents
  • e^f(x) = 0 est impossible — ne jamais écrire cette équation
  • Bien appliquer u' dans (eᵘ)' = u'·eᵘ — ne pas oublier la dérivée intérieure
  • eᵃ × eᵇ ≠ e^(a×b) — c'est e^(a+b) !
M3Fonction Logarithme ln
★★▾
Propriétés fondamentales
  • ln est la réciproque de exp : ln(eˣ) = x et e^(ln x) = x pour x > 0
  • Domaine : ]0 ; +∞[ ; Image : ℝ
  • (ln x)' = 1/x ; (ln u)' = u'/u
  • Strictement croissante ; ln(1) = 0 ; ln(e) = 1
Formules algébriques — SAVOIR PAR CŒUR
ln(a × b) = ln a + ln b // (a,b > 0) ln(a / b) = ln a − ln b // (a,b > 0) ln(aⁿ) = n × ln a ln(√a) = ½ × ln a ln(1/a) = −ln a ln(1) = 0 ; ln(e) = 1
Dérivées avec ln
(ln x)' = 1/x (ln u)' = u'/u // règle de la chaîne (ln|u|)' = u'/u // pour les primitives ∫ u'/u dx = ln|u| + C
Résolution d'équations / inéquations
ln(f(x)) = ln(g(x)) ⟺ f(x) = g(x) ET f(x) > 0 ln(f(x)) = k ⟺ f(x) = eᵏ ln(f(x)) > 0 ⟺ f(x) > 1 (ln croissante, ln(1)=0) ln(f(x)) < 0 ⟺ 0 < f(x) < 1
⚠️ Piège
Toujours vérifier que f(x) > 0 avant d'écrire ln(f(x)). Une équation ln(f(x)) = ... nécessite la condition f(x) > 0 en plus de la solution trouvée.
M4Équations Différentielles
★★★▾
Pourquoi c'est prioritaire ?
Ces équations sont omniprésentes en physique (circuits RC, thermique, radioactivité). Un exercice bac sur deux combine équation diff. et physique !
Forme y' = ay (sans second membre)
Équation : y' = a·y Solution générale : y(t) = C × e^(at), C ∈ ℝ Avec condition initiale y(0) = y₀ : y(t) = y₀ × e^(at)
Forme y' = ay + b (avec second membre) ← LE PLUS COURANT
Équation : y' = a·y + b // Étape 1 : Solution particulière (poser y = k, donc y' = 0) 0 = a·k + b → k = -b/a // Étape 2 : Solution générale y(t) = C·e^(at) + k = C·e^(at) - b/a // Étape 3 : Condition initiale y(0) = y₀ C + k = y₀ → C = y₀ - k = y₀ + b/a // Solution finale : y(t) = (y₀ + b/a) × e^(at) - b/a
✅ Méthode en 5 étapes
  1. Identifier a et b dans l'équation y' = ay + b
  2. Trouver la solution particulière constante k = −b/a
  3. Écrire la solution générale : y = C·eᵃᵗ + k
  4. Appliquer la condition initiale y(0) = y₀ → trouver C
  5. Vérifier en calculant y' et en réinjectant dans l'équation
Interprétation physique
a < 0 (stabilité)
y → −b/a quand t→+∞
Régime transitoire amorti
Constante de temps τ
τ = −1/a (si a < 0)
À t = τ : e^(at) = e⁻¹ ≈ 0,37
⚠️ Erreur classique du bac
Oublier d'appliquer la condition initiale → C reste indéterminé. Toujours trouver C à partir de y(0) = y₀. Un résultat avec C inconnu est incomplet.
M5Nombres Complexes
★★★▾
Forme algébrique
z = a + ib // a = Re(z) partie réelle, b = Im(z) partie imaginaire z̄ = a − ib // conjugué |z| = √(a²+b²) // module i² = −1 // définition de i // Division : multiplier numérateur ET dénominateur par le conjugué z₁/z₂ = z₁ × z̄₂ / |z₂|²
Module et argument
|z| = √(a²+b²) // module (toujours positif) arg(z) = θ tel que cos θ = a/|z| et sin θ = b/|z| // Propriétés : |z₁·z₂| = |z₁| × |z₂| |z₁/z₂| = |z₁| / |z₂| arg(z₁·z₂) = arg(z₁) + arg(z₂) arg(z₁/z₂) = arg(z₁) − arg(z₂)
Forme exponentielle (forme trigonométrique)
Forme trigonométrique : z = |z| × (cos θ + i sin θ) Forme exponentielle : z = |z| × e^(iθ) // Formule d'Euler (fondamentale !) : e^(iθ) = cos θ + i sin θ e^(-iθ) = cos θ − i sin θ // Formules cos et sin : cos θ = (e^(iθ) + e^(-iθ)) / 2 sin θ = (e^(iθ) − e^(-iθ)) / (2i)
Écrire sous la forme A·cos(ωt + φ)
✅ Méthode
  1. Développer A·cos(ωt+φ) = A·cos(φ)·cos(ωt) − A·sin(φ)·sin(ωt)
  2. Identifier les coefficients de cos(ωt) et sin(ωt)
  3. Calculer A = √(coeff_cos² + coeff_sin²)
  4. Trouver φ : cos φ = coeff_cos/A et sin φ = −coeff_sin/A
Plan complexe
M(a ; b) ↔ affixe z = a + ib |z_B − z_A| = distance AB arg(z_B − z_A) = angle de AB avec l'axe réel
Valeurs d'argument remarquables
z réel positif
arg = 0
z réel négatif
arg = π
z imag. pur +
arg = π/2
a = b > 0
arg = π/4
⚠️ Pièges
• Confondre module (distance à l'origine) et argument (angle). • L'argument est en radians (pas en degrés). • Pour la division : toujours multiplier par le conjugué du dénominateur.

Calcul d'intégrale définie
∫ₐᵇ f(x) dx = [F(x)]ₐᵇ = F(b) − F(a) // Propriétés : ∫ₐᵇ f dx = −∫ᵦₐ f dx ∫ₐᵃ f dx = 0 ∫ₐᶜ f dx = ∫ₐᵇ f dx + ∫ᵦᶜ f dx
Aires sous des courbes
// Aire entre f et l'axe des x sur [a;b] : A = |∫ₐᵇ f(x) dx| // valeur absolue ! // Si f change de signe : découper [a;b] aux zéros de f ! A = ∫ₐᶜ f(x) dx + |∫ᶜᵇ f(x) dx| // si f(x) ≥ 0 sur [a,c] et f(x) ≤ 0 sur [c,b] // Aire entre deux courbes f et g sur [a;b] : A = ∫ₐᵇ |f(x) − g(x)| dx
Valeur moyenne et vérification de primitive
Valeur moyenne sur [a;b] : m = 1/(b−a) × ∫ₐᵇ f(x) dx Vérifier que F est une primitive de f : → Calculer F'(x) et vérifier que F'(x) = f(x)
⚠️ Erreur classique
Oublier la valeur absolue dans le calcul d'aire. Si f(x) < 0 sur [a;b], alors ∫f dx < 0 mais l'aire est positive. Toujours analyser le signe de f avant d'intégrer.
M7Transformations dans le Plan Complexe
★★▾
Translation
Vecteur de translation : w̄ (affixe w) z' = z + w // Tout point M d'affixe z → image M' d'affixe z' = z + w
Rotation
Centre Ω d'affixe ω, angle θ : z' − ω = e^(iθ) × (z − ω) // Conservation des distances : |z'−ω| = |z−ω| // θ > 0 : sens direct (anti-horaire) // θ < 0 : sens indirect (horaire)
Homothétie
Centre Ω d'affixe ω, rapport k ∈ ℝ : z' − ω = k × (z − ω) // k > 0 : même côté que z par rapport à Ω // k < 0 : côté opposé // |k| > 1 : agrandissement ; |k| < 1 : réduction
Similitude directe
Composée d'une rotation et d'une homothétie : z' = a·z + b (a, b ∈ ℂ, a ≠ 0) Rapport : |a| ; Angle : arg(a) Point fixe : z₀ = b / (1 − a) si a ≠ 1

(f ∘ g)(x) = f(g(x)) // g appliquée en premier, puis f // Dérivée de la composée (règle de la chaîne) : (f ∘ g)'(x) = g'(x) × f'(g(x)) // Ou sous la forme "dérivée extérieure × dérivée intérieure" : [f(u)]' = u' × f'(u)
Exemples de dérivées composées
sin(u)

−u' × sin(u)
uⁿ
n × u' × uⁿ⁻¹
√u

1/u
−u' / u²

Calcul intégral des composées
∫ f(u(x)) × u'(x) dx = F(u(x)) + C // où F est une primitive de f // Exemples : ∫ u' × eᵘ dx = eᵘ + C ∫ u' / u dx = ln|u| + C ∫ u' × uⁿ dx = uⁿ⁺¹/(n+1) + C

P1Mesures & Incertitudes
★★▾
Types d'incertitudes
// Type A — répétabilité (mesures répétées) : u_A(x) = s / √n s = écart-type expérimental, n = nombre de mesures s = √[ Σ(xᵢ − x̄)² / (n−1) ] // Type B — résolution de l'appareil : u_B(x) = Δx / √3 Δx = demi-largeur de la distribution (précision de lecture)
Composition et écriture du résultat
// Incertitude composée (si A dépend de x et y) : A = x + y ou A = x − y : u(A) = √(u(x)² + u(y)²) A = x × y ou A = x / y : u(A)/A = √((u(x)/x)² + (u(y)/y)²) A = k × x : u(A) = |k| × u(x) // Incertitude élargie (k=2 → confiance 95%) : U = 2 × u(A) // Écriture du résultat : (valeur ± U) unité // ex : (12,5 ± 0,3) V → U arrondi à 1-2 chiffres significatifs → valeur arrondie à la même décimale que U
Conseil bac
Dans les exercices, on demande souvent d'écrire le résultat final avec l'incertitude. Toujours respecter le nombre de chiffres significatifs cohérent avec l'incertitude.
P2Énergie Électrique
★★★▾
Priorité maximale
Ce chapitre est présent dans presque tous les sujets bac STI2D. Maîtriser les calculs de puissance, rendement et régime sinusoïdal est indispensable.
Lois fondamentales en courant continu
Loi d'Ohm : U = R × I (U en V, R en Ω, I en A) Puissance : P = U × I = R × I² = U²/R (P en Watts) Énergie : E = P × t (E en Joules = W·s) En kWh : E(kWh) = P(kW) × t(h) // Association de résistances : Série : R_tot = R₁ + R₂ + ... Parallèle : 1/R_tot = 1/R₁ + 1/R₂ + ... // Pont diviseur de tension : U₁ = U_tot × R₁/(R₁+R₂)
Régime sinusoïdal — LE PLUS IMPORTANT
Signal : u(t) = Uₘ × cos(ωt + φ) Pulsation : ω = 2πf = 2π/T (rad/s) Période : T = 1/f (s) // Valeurs efficaces (dites "rms") : U_eff = Uₘ / √2 ≈ 0,707 × Uₘ Uₘ = U_eff × √2 ≈ 1,414 × U_eff // Réseau français : U_eff = 230 V, f = 50 Hz → Uₘ ≈ 325 V, T = 20 ms // Puissances en régime sinusoïdal : Puissance active P = U_eff × I_eff × cos φ (en Watts, utile) Puissance réactive Q = U_eff × I_eff × sin φ (en VAR) Puissance apparente S = U_eff × I_eff (en VA) Relation : S² = P² + Q²
Rendement et transport de l'énergie
η = P_utile / P_absorbée (sans unité, 0 ≤ η ≤ 1) η% = η × 100% Pertes = P_absorbée × (1 − η) // Transport haute tension (ligne) : Pertes Joule dans la ligne : P_perte = R_ligne × I² → Pour réduire les pertes : augmenter U → réduire I // Transformateur idéal : U₁/U₂ = N₁/N₂ = I₂/I₁ (conserve la puissance : P₁ = P₂)
Lecture d'oscilloscope
Axe Y (tensions) : calibre en V/div → Uₘ = nombre_divs × calibre_Y Axe X (temps) : calibre en ms/div → T = nombre_divs × calibre_X Fréquence : f = 1/T
✅ Méthode calcul de puissance sinusoïdale
  1. Lire Uₘ sur l'oscilloscope → calculer U_eff = Uₘ/√2
  2. Lire T sur l'oscilloscope → calculer f = 1/T
  3. Identifier cos φ (donné ou à calculer)
  4. Calculer P = U_eff × I_eff × cos φ
⚠️ Erreur classique
Confondre valeur de crête (Uₘ) et valeur efficace (U_eff). La valeur "230 V du secteur" est la valeur EFFICACE. La valeur crête est 230 × √2 ≈ 325 V. Toujours préciser laquelle on utilise.
P3Oxydo-réduction & Piles
★★▾
Définitions
  • Oxydation : perte d'électrons (le réducteur s'oxyde → no augmente)
  • Réduction : gain d'électrons (l'oxydant se réduit → no diminue)
  • Couple redox Ox/Red : ex. Cu²⁺/Cu, Fe³⁺/Fe²⁺, MnO₄⁻/Mn²⁺
Écriture des demi-équations
✅ Méthode en 5 étapes
  1. Écrire l'espèce initiale → espèce finale
  2. Équilibrer les atomes principaux (sauf H et O)
  3. Équilibrer les atomes O en ajoutant H₂O
  4. Équilibrer les H en ajoutant H⁺
  5. Équilibrer les charges avec des e⁻
// Exemples de demi-équations importantes : Cu²⁺ + 2e⁻ → Cu // réduction Fe → Fe²⁺ + 2e⁻ // oxydation MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O // réduction (permanganate) Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O // réduction (dichromate) // Réaction globale : multiplier pour égaliser les e⁻, puis additionner
Piles électrochimiques
Anode (−) : oxydation du réducteur (perd des e⁻) Cathode (+) : réduction de l'oxydant (gagne des e⁻) Pont salin : circulation des ions (maintient l'électroneutralité) f.e.m. : E = E₊ − E₋ = E_cathode − E_anode (en Volts) // Les e⁻ circulent de l'anode vers la cathode (dans le circuit externe) // Le courant conventionnel va de la cathode vers l'anode
Quantités en solution
n = m/M = C × V = n_e × Q/F C : concentration molaire (mol/L) V : volume (L) M : masse molaire (g/mol) F = 96 500 C/mol (constante de Faraday)
P4Échanges Thermiques
★★▾
Conduction thermique
Flux thermique : Φ = ΔT / R_th (en Watts) Résistance thermique : R_th = e / (λ × S) e : épaisseur (m) ; λ : conductivité thermique (W/(m·K)) ; S : surface (m²) // Associations de résistances thermiques : En série : R_tot = R₁ + R₂ + ... // même surface, ΔT = ΔT₁ + ΔT₂ En parallèle : 1/R_tot = 1/R₁ + 1/R₂ + ... // même ΔT, Φ = Φ₁ + Φ₂ // Convection (à la surface) : R_th,conv = 1 / (h × S) h : coefficient de convection (W/(m²·K))
Énergie thermique
Chauffage/refroidissement : Q = m × c × ΔT c : capacité thermique massique (J/(kg·K)) ; ΔT = T_finale − T_initiale Changement d'état (T = cst) : Fusion/Solidification : Q = m × L_f (L_f en J/kg) Vaporisation/Condensation : Q = m × L_v Énergie transferrée sur Δt : Q = Φ × Δt
Bilan d'énergie (1er principe)
ΔU = W + Q // Variation énergie interne = Travail reçu + Chaleur reçue Si système clos à volume constant : ΔU = Q Si adiabatique (Q=0) : ΔU = W
P5Énergie Mécanique
★▾
Principe Fondamental de la Dynamique (PFD)
ΣF_ext = m × a (2ème loi de Newton) En composantes : ΣFₓ = m·aₓ ; ΣFᵧ = m·aᵧ
Travail et énergies
Travail d'une force constante : W = F × d × cos α α = angle entre la force et le déplacement W > 0 : force motrice ; W < 0 : force résistante ; W = 0 : force ⊥ dépl. Travail du poids : W_P = m·g·(z_A − z_B) Énergie cinétique : E_c = ½ × m × v² Énergie potentielle : E_p = m × g × h (référence h = 0 à choisir) Énergie mécanique : E_m = E_c + E_p
Théorèmes
Théorème de l'énergie cinétique : ΔE_c = ΣW(F_ext) = somme de tous les travaux Sans frottement → conservation de l'énergie mécanique : E_m = constante → E_c,A + E_p,A = E_c,B + E_p,B Avec frottement (force f) : E_m,B = E_m,A + W_frottement (W_frottem. < 0 → perte d'énergie)
P6Radioactivité
★★▾
Structure du noyau et réactions
Notation : ᴬ_Z X A = nb de masse (nucléons) ; Z = nb atomique (protons) Neutrons : N = A − Z // Types de désintégration : α (alpha) : ᴬ_Z X → ᴬ⁻⁴_(Z-2) Y + ⁴_₂He // perd 4 nucléons et 2 protons β⁻ (béta−) : ᴬ_Z X → ᴬ_(Z+1) Y + ⁰_(-1)e + ν̄ // neutron → proton β⁺ (béta+) : ᴬ_Z X → ᴬ_(Z-1) Y + ⁰_(+1)e + ν // proton → neutron γ (gamma) : émission photon haute énergie // A et Z inchangés // Loi de conservation : A et Z sont conservés (loi de Soddy)
Loi de décroissance radioactive
Nombre de noyaux : N(t) = N₀ × e^(−λt) Activité : A(t) = A₀ × e^(−λt) (en Becquerels, Bq) Masse : m(t) = m₀ × e^(−λt) Demi-vie (période) : t½ = ln(2) / λ ≈ 0,693 / λ Constante : λ = ln(2) / t½ Après n demi-vies : N = N₀ / 2ⁿ Activité : A = λ × N (Becquerel = 1 désint./s)
Dosimétrie
Dose absorbée
D = E/m (Gy = J/kg)
Dose équivalente
H = D × w_R (Sv)
w_R=1 (γ,β) ; 20 (α)
Dose efficace
E = Σ H × w_T (Sv)
tient compte de l'organe
✅ Méthode demi-vie
  1. Identifier λ à partir de la courbe ou de t½ : λ = ln(2)/t½
  2. Écrire N(t) = N₀ × e^(−λt)
  3. Résoudre l'équation pour le temps demandé
⚠️ Piège
Ne pas confondre activité A (en Bq) et nombre de noyaux N. Relation : A = λ × N. L'activité n'est pas le nombre de noyaux !
P7Ondes Sonores
★★★▾
Caractéristiques des ondes
Relation fondamentale : v = λ × f = λ / T v : célérité (m/s) ; λ : longueur d'onde (m) ; f : fréquence (Hz) ; T : période (s) Ondes sonores dans l'air : v ≈ 340 m/s (à 20°C) → v augmente avec la température // Domaines de fréquences : Infrasons : f < 20 Hz Sons audibles : 20 Hz ≤ f ≤ 20 000 Hz Ultrasons : f > 20 000 Hz
Niveau sonore en décibels
L = 10 × log₁₀(I / I₀) (en dB) I₀ = 10⁻¹² W/m² (seuil d'audibilité à 1 kHz) // Seuils importants : L = 0 dB → seuil d'audibilité L = 40 dB → bibliothèque L = 80 dB → rue bruyante L = 120 dB → seuil de douleur // Règles de calcul : Si I double → L augmente de +3 dB Si I × 10 → L augmente de +10 dB n sources identiques → L_tot = L_une + 10×log(n)
Effet Doppler
Source s'approche → fréquence perçue > fréquence émise // son "plus aigu" Source s'éloigne → fréquence perçue < fréquence émise // son "plus grave" f_perçue = f_source × (v ± v_obs) / (v ∓ v_source)
Applications

Cahier des Charges Fonctionnel (CdCF)
  • Fonction Principale (FP) : raison d'être du produit — relie le produit à 2 éléments de l'environnement. Ex : « FP1 : permettre à l'utilisateur d'actionner le mécanisme »

ACV — Analyse du Cycle de Vie
4 phases : 1. Extraction des matières premières (mines, agriculture, pétrole...) 2. Fabrication et transformation (usines, transport, énergie) 3. Utilisation (consommation d'énergie, maintenance, souvent la phase + impactante) 4. Fin de vie (recyclage, réutilisation, décharge, incinération) // Indicateurs d'impact : GWP (Global Warming Potential) : kg CO₂ équivalent Énergie primaire consommée : MJ ou kWh Consommation d'eau Acidification, eutrophisation

TypeSourcesAvantagesInconvénients

Écoconception — 6 principes
  • Durabilité : allonger la durée de vie du produit
  • Réparabilité : faciliter la réparation (vis standardisées, pas de colle irréversible)
  • Recyclabilité : matériaux recyclables, faciliter le démontage (mono-matériaux)
  • Réduction à la source : moins de matière, moins d'emballage
  • Efficacité énergétique : réduire la consommation en usage
  • Substances dangereuses : éviter métaux lourds, solvants toxiques (REACh, DEEE)
